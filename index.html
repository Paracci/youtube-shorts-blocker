Features

Everything you need
to reclaim YouTube.

A focused toolkit for your feed, your downloads, and your privacy. No account, no data collection, no cloud.

Channel blocking buttons

Injects an interactive Block button into every Shorts action bar. Send YouTube's native "Do not recommend" signal with one click — manual, safe, and transparent.

Premium Compliance

Premium-dependent ad automation is fail-closed and remains off until a fresh account result is confirmed. Premium subscribers stay protected across page loads, SPA navigations, and popup interactions.

Ad-safe playback

Explicit ad markers are handled without hiding the entire Shorts player, and playback state is restored after navigation or when the feature is disabled.

Hide Shorts shelves

Surgically removes the Shorts shelf from your homepage. Toggle it on or off instantly from the extension popup for a truly focused experience.

Native Downloader

Open a dedicated downloader page, choose from six output formats and advanced quality profiles, then let the verified yt-dlp + ffmpeg bridge save the result locally.

Global i18n support

Available in 11 languages including English, Türkçe, Deutsch, and more. The popup, setup flow, and standalone downloader share the same translation engine.

01

Block button injection

A MutationObserver watches for new Shorts to load in the DOM. When found, the extension injects a Block button directly into the native action bar — seamlessly styled to match YouTube's design language.

02

YouTube's own signal

Clicking Block triggers YouTube's native "Don't recommend channel" flow programmatically — the same action as using their own menu. The channel handle is then stored in chrome.storage.local.

03

CSS-injected feed hiding

The homepage toggle adds a class to body that CSS selectors pick up. The Shorts shelf disappears instantly — no reload, no flicker. Toggle off equally fast.

04

Privacy-Focused Ad Blocking

Confirmed ad markers are handled with scoped observers and CSS. The player is never hidden wholesale, media state is restored after navigation, and Premium-dependent automation stays off until account state is known.

05

1. Paste a public video URL

The standalone Downloader accepts secure single-video links from YouTube and `youtu.be`. Playlist, credential, search, channel, and non-YouTube URLs are rejected before any native work begins.

06

2. Resolve safe formats

The native host returns normalized resolution, FPS, codec, audio/video, container, and size metadata. The page never receives signed googlevideo.com stream URLs.

07

3. Merge, convert, and save locally

Approved selections become safe yt-dlp arguments; ffmpeg merges or converts the output into MP4, WebM, MKV, MP3, M4A, or Opus inside your chosen download folder.

Privacy

Zero telemetry.
Your data stays yours.

Designed from the ground up with privacy as a first principle — not an afterthought.

No data collected

No analytics, tracking pixels, crash reports, cookies, or account tokens. The extension only contacts YouTube when you actively ask it to resolve or download a video.

Local storage only

All settings, stats, blocked channel handles, language preferences, and download-folder choices live exclusively in chrome.storage.local. On your device. Under your control.

Open source · MIT

Every line of code is public and auditable on GitHub. No hidden requests, no obfuscation, no surprise. Fork it, inspect it, run it exactly as-is.

Installation

Install once.
Keep it local.

The blocker works as an unpacked Chrome extension. The standalone Downloader adds a one-time Windows native-host setup for yt-dlp and verified ffmpeg.

Extension

1
Clone or download the repo as a ZIP from GitHub
2
Open Chrome and go to chrome://extensions/
3
Enable Developer mode (top-right toggle)
4
Click Load unpacked and select the extracted extension folder
5
Visit youtube.com, refresh, and enjoy
For the standalone Downloader:
Install Node.js, then run install_host.bat from the native-host folder. The Setup page verifies both yt-dlp and ffmpeg before any native download begins.
